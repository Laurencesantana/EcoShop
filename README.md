# EcoShop

Projeto de e-commerce desenvolvido em equipe utilizando HTML5, CSS3 e JavaScript.

## Minha contribuição

- Desenvolvimento do CSS da aplicação.
- Implementação da responsividade para diferentes tamanhos de tela.
- Ajustes de layout para desktop e dispositivos móveis.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Interface responsiva
- Catálogo de produtos
- Página de detalhes dos produtos
- Carrinho de compras
- Persistência de dados utilizando LocalStorage

## Sobre o projeto

Projeto desenvolvido em equipe como trabalho acadêmico.
